# trama-demo-web

A hello world frontend used to demonstrate [trama](https://github.com/lukascivil/trama). It shows the greeting returned by [trama-demo-api](https://github.com/lukascivil/trama-demo-api).

```bash
npm install
npm run dev   # http://localhost:5173 — start trama-demo-api first
npm test
```

The API base URL comes from `VITE_API_URL` (see `.env.example`; default `http://localhost:8080`).
